# Good Packaging & Accessories

A modern, fully responsive single-page business website for a packaging and garment accessories company.

🔗 **Live Demo:** [https://goodpa.vercel.app/](YOUR_LIVE_LINK_HERE)

---

## 📌 About the Project

This website was built to showcase a range of packaging and garment accessories (such as Plotter Paper, HDPE Films, Duplex Boards, etc.). The design focuses heavily on a premium, clean aesthetic with a deep indigo color palette, ensuring excellent readability and user experience across all devices, especially mobile phones.

### Key Features

*   **Responsive Design:** Top-tier mobile experience with a hamburger menu and stacked layouts.
*   **Glassmorphism Navbar:** The navigation bar turns into a frosted glass effect upon scrolling.
*   **Performance Optimized:** Zero external icon libraries (using SVG/CSS instead) and lazy-loaded local `.webp` images for lightning-fast load times.
*   **Interactive Sections:** Includes a Welcome Hero section, 4 Feature Blocks (2x2 responsive grid), Core Product Categories, Why Choose Us section, and a detailed product grid.
*   **Contact Section:** A split-layout design with correct office/factory addresses and a styled form.
*   **Floating WhatsApp Button:** Quick contact button fixed to the bottom right corner.
